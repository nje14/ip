# unmark

Marks a task incomplete

## Synopsis

unmark [taskname or number]

## Example usage

```
unmark sleep
```
marks the first occurence of `sleep` (exact match) as incomplete

Expected output:
```
Nyon! (Unmarked [E][ ] sleep (from: 01 Jan 1900 0000 to: 01 Jan 1900 0800))
```

```
mark 1
```
unmarks the task at index 1, as specified by [list](https://github.com/nje14/ip/tree/master/docs/LIST.md)

Expected output:
Similar to above
